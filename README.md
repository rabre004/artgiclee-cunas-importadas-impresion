# Cunas Importadas: casita y galleta para imprimir y troquelar

Los archivos están en **Releases**, en la versión "Archivos de impresión".

- Casita: 88.97 x 80 pulgadas (226.0 x 203.2 cm), 200 ppi.
- Galleta: 34.1 x 48 pulgadas (86.7 x 121.9 cm), 300 ppi.
- Los PDF traen el arte y la línea de corte en tinta directa **CutContour** (sobreimpresión). El sangrado es de 1/4" y el margen de página de 1/2".
- Los SVG son solo la línea de corte. Los PNG son el arte con fondo transparente.
- Los archivos `_cm` son el mismo arte en centímetros. Usar un solo juego: pulgadas o cm.
